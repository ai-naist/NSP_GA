# NSP_GA (Nurse Scheduling Problem Solver using Genetic Algorithm)

このリポジトリは、学部時代の研究で作成した、遺伝的アルゴリズム（Genetic Algorithm: GA）を用いてナーススケジューリング問題（Nurse Scheduling Problem: NSP）を解くプログラムです。
既存のライブラリを使用せず、スクラッチで実装されています。

## 概要

ナーススケジューリング問題は、多数の制約条件（法令、病院の規則、個人の希望など）を満たす勤務表を作成する組合せ最適化問題です。
本プログラムでは、GAを用いてこれらの制約を満たす、あるいは違反を最小化する勤務表を探索します。

## 特徴

*   **複雑な制約条件への対応**:
    *   **ハード制約**: スキル値の合計、各シフト（日勤・準夜勤・深夜勤）の必要人数など。
    *   **ソフト制約**:
        *   勤務回数の均等化
        *   連続勤務の制限（例: 7日以上の連続勤務禁止）
        *   禁止シフトパターン（例: 深夜勤明けの日勤など）
        *   ナース間の相性（Compatibility）
*   **柔軟な設定**:
    *   設定ファイル（iniファイルやテキストファイル）を通じて、ナースの人数、期間、スキル値、シフト体系、個人の希望などを変更可能です。

## 動作環境

*   Python 3.x
*   NumPy

## ファイル構成

*   `initga.py`: メインスクリプト。初期解の生成やGAの実行（または準備）を行います。
*   `protnspga.py`: プロトタイプ実装。
*   `settings/`: 設定ファイル群
    *   `command.ini`: 全体設定（ナース数、期間、世代数、個体数、問題番号など）。
    *   `skill_values.txt`: 各ナースのスキル値。
    *   `shift_systems.txt`: シフト体系の定義。
*   `problems/`: 問題インスタンスデータ
    *   `desireX.txt`: 各ナースの勤務希望（Xは問題番号）。特定の日付に対する休暇希望などを定義。
    *   `compatibilityX.txt`: ナース間の相性データ。

## 使用方法

1.  **設定の変更**:
    `settings/command.ini` を編集して、パラメータを設定します。
    ```ini
    [COMMAND]
    NURSE = 24       ; ナースの数
    TERM = 30        ; 期間（日数）
    POPULATION = 100 ; 個体数
    GENERATIONS = 10 ; 世代数
    PROBLEM = 1      ; 使用する問題データ（desireX.txtなどの番号）
    ```

2.  **実行**:
    以下のコマンドでスクリプトを実行します。
    ```bash
    python initga.py
    ```

## アルゴリズムの概要

1.  **初期解生成**: 制約（特にハード制約）を満たすように、ランダムかつヒューリスティックに初期個体群を生成します。
2.  **評価（Evaluation）**: 生成された勤務表に対し、以下の違反に基づいてペナルティ（コスト）を計算します。
    *   人数違反（各シフトの必要人数不足）
    *   スキル値違反（シフトごとのスキル合計不足）
    *   勤務回数違反（過剰または不足）
    *   禁止パターン違反
3.  **進化**: 交叉（Crossover）、突然変異（Mutation）、選択（Selection）を通じて、世代を重ねて解を改善します（※`initga.py` および `protnspga.py` の実装状況に依存）。
